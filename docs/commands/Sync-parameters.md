# Sync parameters
Changes in a project are normal, but applying those changes can be a tiring task. With this command, you can synchronize the values of multiple parameters between two elements.

## Steps
First, select the first element as the reference, and then select the second element—the one that should receive the information. In this first step, before the main window opens, your selections are only used to identify the category of the elements so that the list of their parameters can be generated in the table.
Next, on the left side, select the reference parameter, and on the right side of the same row, choose the parameter that should receive the value. Make sure the parameters are of the same type. For example, if the parameter on the left is of type Text, then the parameter list on the right will also contain only parameters of type Text.
If you want to synchronize additional parameters at the same time, click the “+” icon to create a new row.

After that, click “OK” to enter the working interface. Make sure your selections are paired correctly: with each click, the first click selects the reference element and the second click selects the receiving element.

When you are done selecting, press Esc to exit the command.

Now, suppose that after some time the parameter values of the reference elements have changed and you want the receiving elements to be updated. Simply repeat steps 1 and 2, and this time, instead of selecting elements again, click the “Update synced parameters” button.

# MEP spacing
This command helps you control the spacing between MEP elements. The distance can be defined either edge-to-edge or center-to-center.

## Steps
First, select one element as the reference. The position of this element will remain fixed, and the spacing of the other elements will be adjusted relative to it. The elements can be ducts, pipes, conduits, or cable trays.

Then specify whether you want the spacing to be calculated based on center-to-center distance or edge-to-edge distance.

Finally, set the desired spacing value, select the target elements in the active view, and click Finish.

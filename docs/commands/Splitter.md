#  Splitter
By this command you can split MEP linear elements (Duct,Pipe,Conduit,Cable tray) to defined segments.

## Steps
In the ribbon click on "PARS-BIM" tab and in "MEP" panel click on "Splitter".

1- In this window, first you can set your priority to split the emelents

<img src="https://pars-bim.github.io/docs/Assets/Splitter.png" alt="Splitter" width="400">

2- Then, set the minimum part length to consider.

3- You can also set the scope of execution for this command.

4- If the scope of execution was not on the select objects, select the categories to apply the command.

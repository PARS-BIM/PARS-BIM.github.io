#  Rule based levels
This command helps you to add and modify levels.

## Steps
In the ribbon click on "PARS-BIM" tab and in "Architectural tools" panel click on "Rule based levels" from "Levels" dropdown button.

1- In this window, you can modify the existing elevation levels. You can change the **elevation or name of any level** as needed.

<img src="https://pars-bim.github.io/docs/Assets/rule-based-level.png" alt="rule-based-level" width="400">

2- If you have multiple floors with equal and repeating vertical spacing, you can use the **“Add Rule-Based Levels”** button to create them automatically.

<img src="https://pars-bim.github.io/docs/Assets/Noanddis.jpg" alt="Select levels" width="400">

3- Review added levels and change the name o height for each if it is necessary.

<img src="https://pars-bim.github.io/docs/Assets/Firstlvl.jpg" alt="Select levels" width="400">

Levels will be created.

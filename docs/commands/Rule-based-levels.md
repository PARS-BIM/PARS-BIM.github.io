#  Rule based levels
This command helps you to add levels when distance between them are equal.

## Steps
In the ribbon click on "PARS-BIM" tab and in "Architectural tools" panel click on "Rule based levels" from "Levels" dropdown button.

1- Specify how many levels do you want to add and the distance between them.

<img src="https://pars-bim.github.io/docs/Assets/Noanddis.jpg" alt="Select levels" width="400">

2- Define first level name and height.

<img src="https://pars-bim.github.io/docs/Assets/Firstlvl.jpg" alt="Select levels" width="400">

3- Review added levels and change the name o height for each if it is necessary.

<img src="https://pars-bim.github.io/docs/Assets/Lvlreview.jpg" alt="Select levels" width="400">

Levels will be created.

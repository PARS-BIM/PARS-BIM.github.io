# 3D Alignment
This command helps you to Align two elements in a 3D view and in a 3D space. In fact it align two element in 3 axis.
## Steps

First select the first element as the reference (Pipe or duct) and then select the second element to be aligned. It will align the second element axis with the first element axis in a 3D view.

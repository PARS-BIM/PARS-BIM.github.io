# Rotate Multiple Elements
This command, Rotates assembled elements around the picked axis.


## Steps

First, select the element around which you want to rotate the rest of the assembly. The selected element may have multiple free ends. For easier positioning and more accurate placement of the guide lines, select the free end that is closest to the rest of the assembly you want to rotate.

Next, select the element that represents the **zero-degree reference line** of the rotation. This defines the direction from which the rotation angle will start.

Finally, select the assembled elements you want to rotate, and click **“Finish”** to apply the rotation.

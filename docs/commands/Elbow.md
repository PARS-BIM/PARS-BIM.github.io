# Elbow
With this command, you can Add elbow to the selected element with specified angle.


## Steps

First, select this command, and then choose the open end of a pipe or duct.

In the opened window, specify the direction in which you want the elbow to be created. Please note that the working plane is oriented such that your viewpoint is from inside the pipe or duct, looking toward its open end.

<img src="https://pars-bim.github.io/docs/Assets/Elbow-window.jpg" alt="Elbow window" width="500">

Refer to the sample image for clarification.

To make modeling easier—especially when working with sanitary drainage piping—45-degree upward and downward directions are also available.

For faster modeling, a keyboard shortcut has been assigned to each direction. The following keys can be used:

Q, W, E, A, S, D, Z, X, C, R, F

As you may notice, all of these shortcuts are grouped together on the keyboard and arranged in a pattern similar to the positions of clock hands, making them easy to remember and use during modeling.

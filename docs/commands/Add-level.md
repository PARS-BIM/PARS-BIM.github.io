#  Add level
This command helps you to add levels easier.

## Steps
In the ribbon click on "PARS-BIM" tab and in "Architectural tools" panel click on "Add level" from "Levels" dropdown button.

1- Specify how many levels do you want to add.

<img src="https://pars-bim.github.io/docs/Assets/Add-level.jpg" alt="Select levels" width="400">

2- Define level name and height for each levels you added.

<img src="https://pars-bim.github.io/docs/Assets/Levels-specifications.jpg" alt="Select levels" width="400">

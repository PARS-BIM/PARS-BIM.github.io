# Match Horizontally
With this feature, you can align MEP elements such as **pipes, ducts, conduits, and cable trays** on the active work plane.


## Steps
There are two ways to perform the alignment:

### 1. Line or Face as the Reference

If you already have a line that you want to use as the alignment reference, simply use the **“Pick”** option.

If you need to create a new reference line, click **“Draw Just One Line.”** As the name suggests, you only need to draw a single line to define the alignment reference.

### 2. Element as the Reference

In this method, you can first specify which part of the **Reference** element the **Target** elements should align with: **Center, Left, or Right**.

Then, specify whether the alignment should be performed along the **X-axis or Y-axis**.

In the **Target** section, you can define which part of the target elements should be aligned: **Center, Left, or Right**.

By enabling **“Multiple Targets,”** you can align multiple elements at the same time.

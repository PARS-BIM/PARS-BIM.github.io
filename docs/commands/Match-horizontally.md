# Match Horizontally
With this command, you can align multiple elements (ducts, pipes, conduits, or cable trays) horizontally.

## Steps
First, simply specify the reference point of the first selected element you want to align to (Left, center, or Right). Then do the same for the target elements. Finally, in the active view, select the reference element first, and then select the elements you want to align horizontally with your reference element.

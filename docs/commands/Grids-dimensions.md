# Grids dimensions
This command helps you to create dimensions between grids automatically.

## Steps
In the ribbon click on "PARS-BIM" tab and in "Architectural tools" panel click on "Grids dimension" from "Magic dimensions".

1- Specify grids range in two range of "Alphabetical" and "Numerical" and then set the necessary offset from each axis. Finally, select approperiate dimension style from the list.

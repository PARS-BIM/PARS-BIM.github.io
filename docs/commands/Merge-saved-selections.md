# Merge saved selections
Sometimes you’ve gone through the trouble of selecting a set of elements and saved them as a Saved Selection, and now you want to add more elements to that set. Normally, Revit does not provide this capability. With this command, you can merge new elements into your previous selection.
## Steps
1- Simply select the levels you want to consider and select pipe or duct systems that you want to select on specified levels.

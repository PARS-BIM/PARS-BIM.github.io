# Select pipes/ducts by level
This command helps you select pipes, fittings, and their accessories, or ducts, duct fittings, and duct accessories based on a specified filter and rule (such as System Type) for the specific levels you choose. This can be extremely useful for managing elements on each floor—for tasks such as quantity takeoff, estimation, and more.
## Steps
1- Simply select the levels you want to consider and select pipe or duct systems that you want to select on specified levels.

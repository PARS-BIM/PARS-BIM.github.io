# Break point
Sometimes in schematic diagrams, lines cross over one another, and you may want to create a break point on one of the lines for clearer visualization. This command helps you create exactly that break point on the lines.

## Steps
For this task, you only need to first specify the cut distance in the opened window. 

<img src="https://pars-bim.github.io/docs/Assets/Break-length.jpg" alt="Sync parameters" width="300">

Then select one line as the reference, and afterwards choose the lines that need to be cut.

<img src="https://pars-bim.github.io/docs/Assets/lines-to-break.jpg" alt="Sync parameters" width="500">

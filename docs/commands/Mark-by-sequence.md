# Mark by sequence
With this command, you can sequentially number the text parameters of selected elements (for example, the Mark parameter of duct accessories) according to your desired rule.

## Steps
1- Select PARS-BIM tab then in the "Common tools" panel and under the "Annotations" dropdown bottun click on "Mark by sequence"

<img src="https://pars-bim.github.io/docs/Assets/Mark-by-sequence.jpg" alt="Mark by sequence" width="500">

First, select the desired category from the “Select Category” section, and then choose the parameter to which the values should be applied from the “Select Parameter” section.

Sometimes you may need additional filtering for selecting and applying the command. If so, enable the “More Filter” option. This allows you to include a specific value within a specific parameter in your filtering criteria. For example, you may want to sequentially name and number the Mark parameter only for duct accessories whose Family Name begins with a certain word.

To do this, in Field 1, specify the first part of the naming rule. For example, you may want the numbering to begin with the prefix BSK.

If you need a separator and a second part for the naming rule, click the “Add field” button to create Field 2, and define the second naming rule just like before.
You can continue this process to add additional fields if needed.

Finally, in the “Counter” section, define the number of digits and the starting value.
You can also specify the type of separator from the Separator section.

After defining all the rules, click “Select multiple” to select the desired elements in the active view. Then, after confirming your selection and clicking Finish inside the plugin window, click “OK” in Revit to apply the final result.

# Rotate Element
This command, Rotates element or elements around its center rotation line.


## Steps

First, select the elements you want to rotate around their own axes. Then, click **“Finish”** to display guide lines showing commonly used angles, helping you avoid selecting an incorrect angle.

Note that the **gray line represents your 0° reference**, and all angles are measured relative to it.

You can also enter a **custom angle value** relative to the gray line (0°), allowing the elements to be rotated by exactly the desired angle.

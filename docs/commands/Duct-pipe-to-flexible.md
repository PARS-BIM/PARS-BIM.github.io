# Duct/Pipe to flexible
This command helps you easily convert a pipe or duct into a flexible one—something that was needed but not available in Revit’s default tools.

## Steps
1- Select PARS-BIM tab then in the "MEP" panel and click on "Duct/Pipe to flexible"

In this window, if you want to convert an entire duct or pipe into its flexible version, simply ignore the “Flex Length” section, as it is only related to the “Connected to accessories” feature.

Then, in the following sections, you can specify the type of flexible element you need: round flexible duct, rectangular flexible duct, or flexible pipe.
(Choose whichever applies to your case.)

Finally, click the “Select Pipe or Duct” button and select the pipes or ducts in the project that you want to convert to flexible.

<img src="https://pars-bim.github.io/docs/Assets/Duct-pipe-to-flex.jpg" alt="Select levels" width="500">

If you want to add flexible duct or flexible pipe segments to both sides of an accessory, simply follow these steps:

First, specify the length of the pipe or duct connected to the accessory that you want to convert into a flexible segment using the “Flex Length” section.
Then click the “Connected to accessories” button.

Now, in the newly opened window, you have several options:

Select in view:
Choose this option if you want to manually select the accessories yourself in the active view.
All in active view:
Choose this option if you want the plugin to automatically process all selected accessory types within the active view. In this case, select the desired accessory types from the available columns.
All in project:
Choose this if you want the plugin to automatically process all selected accessory types throughout the entire project. Again, select the relevant accessory types from the available columns.
